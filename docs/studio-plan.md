# 交互工作台 · 实施与验收
用户已选定沿用 Blueprint 的项目交互和机械设计流程，将最后的采购改接淘宝。首个实物对象是已有的 Pico 指示器，不把模板展示为任意几何生成。

1. 输入项目目标、澄清与修改，记录当前设计。接线节点、零件、机械部件与采购入口围绕同一项目切换。
2. 选择机械部件、修改参数、旋转检查并下载相应文件；区分浏览器预览、引擎输出与未验证的实物配合。
3. 登录、授权、加购和支付分别处理。模型只检索公开商品，登录信息不发送至模型，不凭搜索命中猜测 SKU 或标记已加购。
4. 发布静态交互前核对真实浏览器操作与文件；仅在有服务凭据及供应商授权时验证对应外部能力。
