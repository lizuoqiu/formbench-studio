# Sensor history in the hardware preview

A device which promises to show past measurements must preserve observable information from its inputs. Its screen being on establishes nothing about that promise. Record typed source events and elapsed session time; allow capture and review in the generated interaction contract. Devices without this requirement keep the existing behavior. The preview models events supplied by the tester, not real measurements, sleep stages, or unsampled intervals.

1. Validate the optional display, capture and review states and wired feedback sources. Replay contrasting input traces through the same state engine and carry the evidence into review.
2. Show a usable recorder with elapsed time and captured entries in the normal workbench, including designs without a physical pushbutton. Check it in a real browser. Make provider and component progress accurate.
3. Deploy, then type each brief from the published homepage in order. Hold downstream tests when a prerequisite fails. Analyze the unchanged running jobs and keep both UI and log evidence.
